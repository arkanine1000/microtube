# Listening Notes

MicroTube is an audio instrument, not a cure, treatment, or diagnostic tool.
Use it with the same care you would use for any steady headphone sound.

## Headphones matter

Binaural beats need separation between the ears. Headphones are strongly
recommended. Speakers mix the left and right tones in the room, which changes
the effect into ordinary acoustic beating.

Open-back, closed-back, expensive, cheap: all can work. The most important
thing is comfort.

## Keep the volume modest

Steady tones can become tiring. Start low. If you want more presence, try a bit
of warmth or mist before raising the volume.

If you feel discomfort, pressure, headache, dizziness, or irritation, stop.

## Do not fight the sound

The best sessions are usually simple. Pick a beat range, set a comfortable
volume, and give yourself a few minutes before making judgments.

If you constantly adjust the controls, you are testing the interface more than
listening to the sound.

## Expectations

Some people find binaural beats calming. Some find them distracting. Some feel
almost nothing. MicroTube gives you a precise and flexible stimulus, but it
does not guarantee a result.

The band names are useful language, not promises.

## Good uses

- Background focus with low warmth and little mist.
- A short transition into rest using Alpha or Theta.
- Sound design exploration with Harmonics and Spectrum.
- Generative listening with Emergence and Penrose mode.

## Poor uses

- Very high volume.
- Listening while driving or doing risky work.
- Treating discomfort as something to push through.
- Expecting the app to replace medical or mental health care.

Stay curious, but stay ordinary about it: if it feels bad, stop.
