# Presets And Sequences

Presets and sequences are two different ways to avoid starting from a blank
panel.

Presets are single snapshots. Sequences are timed programs.

## Presets

The quick presets set the main carrier and beat:

- Deep Sleep uses a Delta beat.
- Meditation uses a Theta beat.
- Relaxation uses an Alpha beat.
- Focus uses a Beta beat.
- Flow State uses a Gamma beat.

They are simple on purpose. Pick one, listen, and adjust.

Press `S` to save the current Studio state as a local preset. Local presets
remember the sound, mist, timbre, drift, emergence, gravity, spawn mode, and
visual mode. They are stored in your user config directory and show up after the
built-ins in the preset menu. Press `d` on a local preset in that menu to delete
it.

## Sequences

A sequence changes settings over time. Beat and base frequency glide between
steps. Some sequences also automate timbre, mist, emergence, gravity, drift,
spawn mode, and visual mode.

This lets MicroTube behave more like a composed session than a static tone.

## Journey Through The Cosmos

The longest built-in sequence is a 13-step arc. It moves from high Gamma into
slower bands and then returns. Step lengths follow Fibonacci numbers, and the
base frequency descends before snapping back.

You do not need to know the theory to use it. Treat it as a long-form demo of
what the whole engine can do.

## Manual control during automation

When a sequence is running, it owns the parameters it automates. You can still
watch and listen, but manual changes to those parameters may be overwritten on
the next update.

If you want full manual control, stop using sequences and work from a preset or
from the current state.

## Practical advice

Use presets for quick sessions. Use sequences when you want motion but do not
want to steer.
